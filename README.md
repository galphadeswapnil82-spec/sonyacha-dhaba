# sonyacha-dhaba
Create a modern, responsive website for a highway restaurant named "Sonyacha Dhaba & Family Restaurant" located on Latur Kalam Highway, Shiradhon, Maharashtra, India. The design should have a rustic Indian dhaba theme with warm golden lighting, wooden textures, and a cinematic rural atmosphere. Include a full-width hero section with a background image of a traditional dhaba at sunset, glowing lights, and a bold title with tagline "सोण्यासारखा चवदार अनुभव".

Add navigation menu: Home, Menu, About, Contact.

Home section: welcoming text, highway vibe, family-friendly dining, authentic Maharashtrian food.

Menu section: split into Veg and Non-Veg categories.
Veg items: Veg Thali, Paneer Masala, Aloo Sabji, Jeera Rice, Tandoor Roti, Salad.
Non-Veg items: Chicken Curry, Chicken Tandoori, Chicken Thali, Egg Curry, Chicken Fry.

About section: describe traditional dhaba experience, warm hospitality, rural Maharashtra ambiance.

Contact section: Address - Latur Kalam Highway, Shiradhon, Maharashtra. Include phone number placeholder and map section.

Style: dark theme with golden accents, soft shadows, glowing lights, cinematic look, mobile-friendly layout, smooth scrolling, modern UI, clean typography.

Add footer with copyright "© Sonyacha Dhaba".

Make it visually rich, realistic, and suitable for a restaurant business website.
